# Mahjong Jewel — offline Android preview 0.5

ZIP内の元のオンライン試作品をリポジトリ直下に展開し、`offline/` に通信不要の対局を追加しました。

## 遊ぶ

ブラウザ: `node server.js` を起動し `http://localhost:3000/offline/index.html` を開く。
Android: `.github/workflows/android.yml` の実行が成功したら Actions → 対象実行 → Artifacts → `mahjong-jewel-debug-apk` をダウンロードし、ZIP内の `app-debug.apk` をインストールする。
APKはデバッグ署名の試験版です。Android 8以降。INTERNET権限はなく、HTML/JS/麻雀エンジンをAPK内に同梱。初回起動から通信不要です。

## 実装

- 人間1人対CPU3人、東風戦、25,000点開始。CPUは向聴数と有効牌を評価。
- majiang-coreによる通常役・符・点数、フリテン、ロン／ツモ、リーチ、チー／ポン／カン、ドラ／裏ドラ。
- 順位チップ +50/+25/−25/−50。点数差をチップに変換しない。同点は起家からの席順。
- 終局時に順位チップと祝儀収支を別々にlocalStorageへ累積保存。同じ対局IDは二重計上しない。成績のJSON出力。
- 55,000点以上でコールド。0点未満でトビ。和了で飛ばした相手からトビ賞10枚。
- アプリ終了時の途中対局復元は未対応。保存成績は端末内のみで、アプリデータ削除で消えます。

## Jewel構成と今回確定したルール

東風開始前にポッチを最大3種類・各種類1枚まで自由に選びます（0種類も可）。画面でアメジスト白／ゴールド發／ガネクリ北を選べます。それぞれ対応する通常牌1枚を置き換え、対局中は固定です。ラピス5萬・アメジスト5筒・トルマリン5索は各1枚ずつです。

- 白ポッチ: リーチ後にツモった場合、合法な待ち牌に置換して和了できます。
- アメジスト白ポッチ: 白ポッチの条件に加え、手牌・副露に使って和了した場合もアメジスト効果（基本祝儀+1枚、その後2倍）を適用します。
- ゴールド發ポッチ: 基本祝儀+4枚。役ありテンパイなら、副露ありでもツモ時にオールマイティ。役のない手をJewel加翻だけで和了させることはありません。
- ガネクリ北ポッチ: リーチ後のツモ時にオールマイティ。祝儀はガーネット（ドラ表示牌の数字の最大値、字牌表示は同位置の裏表示牌を参照）とクリスタル（和了した実際の牌の数字、字牌0）の大きい方。手牌・副露に使った場合にも適用します。
- 全役解放: 東風開始時に19種の通常手役から1つ抽選し、東風中は固定。対象役の和了は基本祝儀+5枚。ロンは放銃者、ツモは各家が支払います。

オールマイティはツモったポッチにだけ適用し、既に手牌にあるポッチや他家の捨て牌は通常の白／發／北として扱います。通常のドラ・役・フリテン判定でも元の牌種を保持します。和了は合法な置換の中から最高点の形を選びます。

元ZIP由来のラピス・アメジスト・トルマリン計算は暫定仕様です。各色5は赤ドラ1翻＋Jewel1翻。アメジスト白も同等、ゴールド發とガネクリ北はJewel1翻。通常祝儀は一発・裏ドラを基本祝儀とし、ラピス=最終翻数枚、トルマリン=和了前の持ち点の百／千／万の最大数字枚、アメジスト=1枚加算後2倍です。全役解放、ゴールド、ガネクリを基本祝儀へ加えた後、アメジストで倍化します。

**フルジュエル役満:** 数牌の宝石3種類（ラピス・アメジスト・トルマリン）をすべて使用し、ポッチを2種類以上使用した合法な和了で成立します。副露も含めて判定します。

ラピス・アメジスト・トルマリンの細かい翻数と計算順は元ZIP由来の暫定仕様です。

## テスト・ビルド

```sh
npm test
node scripts/bundle.js
# Android SDK 35 / JDK 17 / Gradle 8.9 がある環境
 gradle -p android assembleDebug --no-daemon
```

外部npmパッケージは不要。`vendor/majiang-core` をMITライセンスで同梱しています。
`node test/offline.test.js` は通常和了、Jewel加翻、収支保存、コールド境界、フリテンとロン提示、CPU同士の8東風戦と、4種ポッチ各3東風戦を検証します。
Android APKはGitHub Actionsでビルド成功済み。ローカルにはGradle/Android SDKがなく、ブラウザ実行もソケット制限で起動できないため、スマホ幅のブラウザテストはActionsで打牌・CPU進行・成績の再読み込みを検証します。Android実機での操作確認は未実施です。

元試作品の `server.js`、`game.js`、`socket.js`、既存UIとテストも残しています。オンライン機能はAndroidから使用しません。
