# オフライン起動と近距離対戦

- PWA: 公開ファイルをバージョン付きCache Storageへ一括保存。全ファイルの取得が完了してから準備完了マーカーを保存し、インストールを完了。更新は開いている旧版のタブを閉じてから有効になります。API・他オリジン・POST・遠距離対戦の認証付き画面/スクリプト・ルートURLはキャッシュしません。近距離用の共通クライアントは別名にして保存します。成績は既存のlocalStorageを維持します。保存の永続性はブラウザに依存します。
- 近距離対戦: WebRTCのordered/reliable DataChannelによる親機中心の通信。iceServersは空。STUN/TURN/接続仲介サーバーなし。招待・応答のSDP/ICEを手動交換。各参加者と別の接続を作成します。
- 対局処理: 既存のRoomsをNode/Web Crypto共通化し、ブラウザの同じエンジンで実行。人間2〜4人、空席CPU。親機だけが設定・開始でき、全員の準備完了が必要です。切断席は既存の操作タイムアウトで代行します。親機のスリープや切断からの復元、親機移譲、切断席への再参加は未対応。
- 信頼境界: 参加情報は接続ごとに固定し、他の席の認証情報に差し替えても拒否。接続ごとの同時リクエスト・頻度・メッセージ上限あり。大きな終局棋譜は16KB未満のフレームに分割して再構成します。親機は山を管理するため、親機の不正防止を保証しません。友人同士向けです。
- 近距離の成績は既存のルーム対戦の成績キーに保存。参加情報はメモリのみで、リロード復帰は不可。遠距離対戦の既存セッションとは分離します。
- 五等サンマはひとり対局のみ。近距離対戦は四人麻雀。

## 検証

`npm test` と `node scripts/build-pages.js` を実行。Playwrightを用意して `node scripts/smoke-ui.js`、`node scripts/smoke-sanma.js`、`node scripts/smoke-online.js`、`node scripts/smoke-nearby.js` を実行します。近距離テストは独立した4つのブラウザコンテキストのWebRTC接続、ホスト制限、席の認証差し替え拒否、大きなメッセージ、実際の合法操作、切断通知を検証し、その後ネットワークを無効にして各画面の再起動と五等サンマの牌画像・対局を検証します。実機同士や各種ルーターでの接続性は別途確認が必要です。

接続手順は `public/offline/connection-guide.html`。公開先のルートと /mahjong-jewel/ の両方の相対パスに対応しています。外部の遠距離サーバーへのデプロイはこの変更には含みません。
