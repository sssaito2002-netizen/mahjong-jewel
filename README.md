# Jewel Mahjong — offline Android preview 0.6

人間1人対CPU3人で遊ぶ、通信不要の東風戦アプリです。元ZIPはリポジトリ直下へ展開済み。通常麻雀はMITのmajiang-coreを同梱しています。

## 遊ぶ

- ブラウザ: `node server.js` → `http://localhost:3000/offline/index.html`
- Android: Actionsの成功した実行 → Artifacts → `mahjong-jewel-debug-apk` → ZIP内の `app-debug.apk` をインストール。
- Android 8以降。HTML、JS、エンジンをAPK内に同梱し、INTERNET権限はありません。

対局画面は緑の卓、四方向の河、中央の局・ドラ・点数、手前の手牌という配置です。牌をタップして打牌し、リーチを選ぶと宣言可能な牌を選べます。設定から宝石の構成を選んで新しい対局を始められます。

## 宝石選択

**同じ宝石牌は各1枚、同じ元牌には宝石を2枚まで。通常牌と置き換え、136枚を維持します。** 例: アメジスト5筒とパール5筒は同時に入れられます。ポッチは最大3種類。

note本文で効果を確認した19種類をカタログ化しています。選択した構成は東風戦中は固定。候補一覧、参照記事、効果と計算順は [docs/jewel-rules.md](docs/jewel-rules.md) を参照してください。カーネリアンを使った和了では祝儀優先／翻数優先を選べます。CPUは祝儀優先、翻数不足時は救済側を使用します。

## 対局と保存

通常役・符・点数、フリテン、ロン／ツモ、チー／ポン／カン、リーチ、ドラ／裏ドラ、流局と東風進行。25,000点開始、55,000点以上でコールド、0点未満でトビ。和了で飛ばした相手からトビ賞10枚。

順位は **+50 / +25 / −25 / −50枚**。持ち点差をチップへ換算しません。同点は起家からの席順です。終局ごとに順位チップと祝儀を別々に端末内localStorageへ累積保存し、同じ対局IDを二重計上しません。成績JSONの保存・共有が可能です。

全役解放は東風開始時に19種の通常手役から1つ抽選して固定。基本祝儀+5枚、ロンは放銃者、ツモは各家から受領します。フルジュエルは選択した数牌宝石すべてとポッチ2種類以上を使用した合法な和了で役満（数牌宝石の選択が0なら不成立）。

## 検証とAPK

```sh
npm test
node scripts/bundle.js
# Android SDK 35 / JDK 17 / Gradle 8.9
 gradle -p android assembleDebug --no-daemon
```

ゲーム実行に外部npmパッケージは不要。CIではPlaywrightを使い、390pxのスマホ画面とPC画面で、牌の直接タップ、CPU進行、選択制限、横はみ出し、外部通信なし、成績の再読み込みを確認して画面画像を保存します。

単体テストは役・点数、ポッチ、各宝石の効果、構成制限、同じ5の物理的識別、チー／ポン／カン、フルジュエル、保存を検証。複数の宝石構成でCPU対局を完走させ、点数・祝儀の合計を確認します。

Androidはデバッグ署名の試作版です。実機での操作確認、途中対局復元、オープンリーチ、ドラ表示牌から通常牌へ効果を付与する熱狂Jewel部独自ルールは未対応です。一般的なリーチとターコイズによる鳴きリーチは対応しています。独自画像・CSSを使用し、天鳳の画像・ロゴ・プログラムは使用していません。

元試作品のオンライン用ファイルは残しています。Androidはそれらのサーバーに接続しません。
