# 宝石麻雀 ルーム対戦の試作・無料デプロイ

## 実装済み

- 合言葉（8桁）で作成・参加。人間2〜4人、残りはCPU。
- ホストによる宝石構成の設定、準備完了、対局開始。設定変更時は全員の準備を解除。
- サーバーで既存の麻雀エンジンを実行し、合法手・点数・特殊牌・祝儀を決定。
- 他家の非公開手牌と未公開の山は送信しない。端末は本人向けイベントを受け取る。
- 通信は同一オリジンのHTTPS長ポーリング。外部ライブラリ／DBは不要。
- 打牌20秒、鳴き10秒、リーチ・和了確認15秒。タイムアウト時はツモ切り／見送り、和了可能なら自動和了。CPU代行は切断猶予120秒待ちではなく各操作期限から適用。
- 再読込・一時切断後は、同じタブの参加トークンで履歴を受信して復帰。
- 操作IDで二重送信を無害化。サーバーが提示していない操作を拒否。
- 東風終了結果を端末内へ保存（オフライン成績とは別、対局IDごと1回）。
- 8部屋まで。無操作2時間で削除。再戦は新しい部屋を作成。

## 無料サーバーでの制限

Render Freeの公式案内: https://render.com/docs/free

15分の無通信で休止し、次のアクセスで起動に約1分。再起動や再デプロイがあり、メモリ・ローカルファイルは維持されないため、**途中対局はサーバー再起動をまたいで復元できません**。試作段階ではDBを使わず、この制限を画面にも表示しています。

同じタブの再読込には復帰できます。タブを閉じた場合の参加情報保持、別端末への引継ぎ、永続ログ、アカウント管理、ランキングは未実装。準備中の明示的な席削除とホスト移譲も次の段階です。ホスト切断後も対局開始済みならサーバーが進行します。

無料枠には実行時間・帯域・ビルド分数の上限があります。カード未登録時は枠超過で停止します。課金を避けたい場合は有料プランへ変更せず、支払方法と利用上限を確認してください。アカウント作成時にサービス側の本人確認が必要になる可能性があります。

## スマホからのデプロイ

[Renderで無料サービスを作成](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Fsssaito2002-netizen%2Fmahjong-jewel%2Ftree%2Fcodex%2Foffline-android)

1. RenderにGitHubでサインイン。
2. 上のリンクでBlueprintを開き、`houseki-mahjong-online` のプランが **Free** であることを確認。
3. 作成を実行。`render.yaml`でブランチ・起動コマンドを指定済み。
4. Liveになったらサービスの `https://…onrender.com/` を開く。これは対人モードの入口。
5. 2台で同じURLを開き、片方で部屋作成、もう片方で合言葉参加。全員が準備完了、ホストが開始。

URLはRenderが決めます。**GitHub Pagesには対戦サーバー機能はありません**。既存のgithub.ioのオフライン対局は引き続き利用できます。オンラインURL確定後にPagesからの入口を追加します。

Blueprintで作れない場合はNew → Web Serviceで公開リポジトリを選択し、下記を指定します。

| 項目 | 値 |
| --- | --- |
| Branch | `codex/offline-android` |
| Runtime | Node |
| Build Command | `node scripts/bundle.js` |
| Start Command | `node online/server.js` |
| Instance Type | **Free** |
| Health Check | `/health` |
| Auto Deploy | Off（対局中の自動再起動を避ける） |

## ローカルでの起動と検証

Node.js 22以降で `node scripts/bundle.js` → `npm run start:online` → http://localhost:3000/ 。従来の `npm start` は元のプロトタイプサーバーなので使い分けます。

`npm test` は2人＋CPU2人で東風完走・祝儀保存元の整合・手牌非公開・不正操作拒否・二重応答・タイムアウト進行を検証します。`scripts/smoke-online.js` はPlaywrightを使い、独立した2ブラウザで参加・宝石同期・対局操作・再読込復帰・認証とOriginチェックを検証します。CIの `Online room integration` を参照してください。
