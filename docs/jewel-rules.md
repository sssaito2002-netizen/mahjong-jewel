# 宝石カタログと採用裁定

公開されたメンリー氏のnote本文から、ゲームの効果を要約して独立実装したものです。記事本文や画像はアプリに転載していません。

## 資料

- [初期構成（2021）](https://note.com/menzenreach/n/ne611720a6e37): エメラルド、アクアマリン、ルビー、シルバー、トパーズ。
- [ver2（2023）](https://note.com/menzenreach/n/n29f9fdb978fd): アメジスト更新、カーネリアンの選択、クリスタル。
- [ver3（2023）](https://note.com/menzenreach/n/nc00d9a47e5d7): パール、ゴールド發、役満祝儀。
- [ver4（2024）](https://note.com/menzenreach/n/n281285c5140e): ガーネット更新、ターコイズ、ブラックダイヤ更新。
- [ver5（2024）](https://note.com/menzenreach/n/ncbc49b792147): トルマリン更新、ラピスラズリ。
- [ver6（2025）](https://note.com/menzenreach/n/nb34690c45187): ガネクリ北、アメジスト5索、ゴールド併用。

## ユーザー指定を優先した裁定

- 各種類1枚・同じ元牌2枚まで・136枚・ポッチ最大3種類。重複が必要なダブル同種の効果は発生しません。
- 全役解放は東風ごとに対象手役1つを抽選、基本祝儀5枚。ロンは放銃者、ツモは各家払い。
- フルジュエルは選択した数牌宝石すべて＋ポッチ2種類以上。数牌選択0の場合は不成立。
- ガーネットは字牌表示ごとに対応裏を参照するユーザー指定の方式。記事の「表がすべて字牌なら裏を見る」という表現とは区別します。
- 順位チップ50/25/−25/−50、コールド55,000、トビ賞10枚。

## オールマイティと計算順

白系とガネクリ北はリーチ後にツモった場合、ゴールド發は役ありテンパイなら副露ありでもツモった場合に置換候補を判定。手牌・副露で普通に使った場合も各祝儀は適用します。通常の牌種・4枚制限・フリテンの判定では元牌を保持します。

通常役とJewel役、宝石加翻、カーネリアンの選択、パール倍化、点数計算、通常祝儀・宝石祝儀・解放役祝儀の加算、アメジスト倍化、支払いの順です。オールマイティは最高点になる合法な和了形を採用します。クリスタルは置換した和了牌の数字を使います。

ゴールド5筒とゴールド發を実際の發として併用した和了では基本祝儀+10枚。發ポッチを別の牌へのオールマイティとして使った場合、この併用加算はしません。

役満祝儀はロン20／ツモ各10、数え役満はロン10／ツモ各5、ダブル役満は倍。本役満の複合は合算します。Jewelは宝石3種類を使う1翻役です。宝石単体を「Jewel1翻」として重複加算しません。

## 対象外

2026年の熱狂Jewel部記事にある「表裏表示の宝石から通常牌に効果付与」、同種を2枚必要とするダブル牌、オープンリーチの独自祝儀は今回の選択機能には含めていません。記事で名前だけ触れられ、効果の定義が確認できない別牌は推測で追加していません。

## 追加の卓ルールと表示

1本場は合計1,500点。ロンは放銃者から1,500点、ツモは各家500点。本場点は祝儀には加えません。東と西はともに場風牌（自風との重複は各1翻、雀頭の符にも反映）。和了画面で加算祝儀と倍化後の内訳を確認でき、リーチ宣言は確認ポップアップと卓上表示で通知します。
