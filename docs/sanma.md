# 五等サンマ：試作版の実装範囲

参考：https://note.com/fondjp/n/n7ba21b49b651 （ゆる五等サンマ）

利用者の指定を優先し、東風戦・白ポッチありで開始する。四人用 Game の席を擬似的に抜く方式は使わず、三人専用の状態遷移・決済・保存を分離する。オンラインは既存の四人用・パスワード保護のままとし、このモードは人間1人対CPU2人のローカル対局に限定する。

## 実装

- 三人のツモ順、東1〜3局、ノーテン親連荘、オーラス和了止めなし、0点以下で終局。
- 萬子2〜8なし。通常108枚に春夏秋冬4枚または8枚を追加。白1枚を白ポッチへ置換。5筒・5索はそれぞれ金2枚・赤2枚。通常の宝石選択枚数ルールはこのモードに適用しない。
- 北抜きと華の自動抽出、補充。抜き北にロン不可。一発を解除しない。手牌の北は国士・四喜和だけに認める。
- ドラ表示2枚。萬子1の次ドラは9。表示・裏を各2枚確保し、カンごとに追加表示・裏を各1枚確保する。残りの山はツモり切る。カンは最大4回で、追加表示2枚＋補充の山が必要。
- 通常の役、ポン・大明槓・暗槓・加槓・槍槓・リーチ。チーなし。フリテンと三人目のリーチはオープン必須（1翻・全晒し）。リーチ後は手出し禁止、合法な待ち不変暗槓と抜き北に限定。和了可能時の見逃し不可。
- 白ポッチはリーチ後のツモで万能、強制和了、サイコロ対象。5に置換しても赤・金を付けない。冬の失敗保障に加算。
- 七対子は4枚を2対子に使える。チャンタ4翻・純チャン6翻で喰い下がりなし。萬子混一色と清一色七対子は役満。14翻から数え役満。役満複合・ダブル役満なし。
- 30符固定・支払いは千点切り上げ。ツモ損なし：子ツモは基礎点の2.5倍を親、1.5倍を子が支払い、親ツモは各3倍。夏の打点ランクは1翻→2翻→3翻→満貫→跳満→倍満→三倍満→役満→5倍満。5倍満子ツモ15,000/25,000、親30,000オール。
- 1本場ロン1,000点・ツモ各1,000点。流局の場2,000点。ダブロン時の供託・本場は近い和了者へ、親和了があれば連荘。
- 一発・裏・北・金、三倍満以上、本役満、トビ賞の祝儀。サイコロは通常祝儀と別の各家払い、ゾロ目は続行・ピンゾロ20枚。病的な乱数源でも停止するよう最大100回で打ち切る。
- 四北四華100枚オール、八華100枚オール、四北八華200枚オールは他祝儀を置換。表示牌も四北・四華の種類判定に数える。
- 成績は `houseki-sanma-results-v1` に保存。既存四人麻雀・オンラインから分離する。順位チップは東風の沈みウマを採用し、点棒精算を別表示。未完の対局復元には非対応。

## 華の設定

`flowerRules` の識別子をバリデーションし、表示・効果計算・保存設定を一致させる。

| 華 | 基本 | 別設定 |
|---|---|---|
| 春 | 春枚数×抜いた華の総数との差分を即時各家払い | 華抽出ごと1枚オール／無効 |
| 夏 | 打点ランクアップ、複数枚加算 | 翻数加算／無効 |
| 秋 | 5筒・5索の赤金とは別に追加ドラ | 祝儀加算／無効 |
| 冬 | アリス、2枚でチューリップ | チューリップ、2枚で上下段／固定祝儀／無効 |

表示牌の華は全員に作用する。春の表示は和了祝儀5枚／枚。冬のアリスは門前2枚・副露1枚、チューリップは1枚。一発と白ポッチでそれぞれ失敗保障1回を加算。華設定は対局開始後変更しない。

## 未対応・暫定裁定

人和（レンホー）は不採用。流し役満・オープンリーチ押し出し・北抜きロン等は追加オプションで選択可能。手動牌操作のチョンボはアプリが非法操作を拒否するため実装しない。記事の完全再現と表示しない。複雑な例外を含むため試作表記を維持する。

## 確認

牌構成・華の連動・点数表・抜き北・白ポッチ・待ち不変カン・ダブロン・オープンリーチ・CPUの非公開情報隔離・別保存をテスト。固定乱数24対局を通じ、合法手のみ・終局・点棒と供託105,000点保存・チップゼロサムを確認。ブラウザでは390×844、844×390、844×290、実対局・和了確認・保存・再戦・成績画面を検証する。

## 追加設定（2026-10-22）
- ポッチは白・逆・倍・逆倍を個別選択。各種類1枚、0〜4枚。通常白と置換し、白系は合計4枚を維持します。リーチ後に引いたポッチだけが万能牌になります。
- 逆は和了祝儀を支払う、倍は祝儀2倍。サイコロ・和了時の華の祝儀も対象です。抜いた時点の春祝儀・トビ賞・順位チップ・点数は対象外です。
- 一発ポッチの追加サイコロは任意設定。通常のサイコロチャンスとは別に2個を1回振り、出目の合計を各家から受け取ります（逆・倍適用）。
- 春：リーチ和了時チューリップを追加（この設定では即時祝儀なし）。冬：華1枚につきサイコロ1個を1回振る選択肢を追加。
- 秋：5筒・5索のドラ寄与（赤金＋表示・裏）と金牌祝儀を2倍にする設定。華が複数でも倍率は2倍です。
- 人和（レンホー）は不採用。第一ツモ前のロンでも、完成した和了形と通常の役が必要です。大三元・大四喜の包は最後の必要な刻子を鳴かせた人が責任者。ツモ全額、ロン折半、本場は責任者。祝儀は通常どおりです。

## 身内ルール・メニュー追加（2026-10-23）

`offline/sanma/variants.js` が設定項目と従来値・身内プリセットの定義です。ホームは宝石麻雀4人／五等サンマ3人に分け、各ひとり対局は設定から開始します。五等サンマの対人対戦は準備中と明示しています。宝石麻雀にはオープンリーチ2翻・2000点（ダブル3翻）を追加しました。

設定差分と採用条件は `sanma-rules.html` に自動生成され、オフライン保存の対象です。従来の成績・設定を維持し、追加設定はゲーム履歴にも保存します。身内プリセットは元の設定を変更するボタンであり、実行中の対局を途中で変更しません。人和は両設定とも不採用です。

- 4枚使い七対子4翻、8枚使い8翻、12枚使いは本役満。小車輪は混一色七対子6翻で、4枚使いとの組合せ8翻、8枚使いとの組合せ12翻。大車輪は清一色七対子の本役満です。
- 門前オールスターは副露せず、選択した牌構成に含まれる赤・金の5をすべて使用した場合。
- リーチのみ／リーヅモのみ役満は通常の完成形が前提。一発・裏ドラ・華（表示／裏表示を含む）・抜き牌・リーチ前のドラ切りがある場合は除外します。
- 一発と裏ドラの祝儀各1枚、即ポッチの3枚は一発込み。独立したスイッチで変更可能。
- 複合役満は最大ダブル。点棒と通常祝儀は2倍、出目金は同じ出目の倍払いではなく2回振ります。シュバとトビが重なる倍率も別に計算し、全員の収支を保存します。
- 北抜きロンは指定役満のみで、自分が北を抜いていればフリテン。手牌の北は国士・四喜・字一色・萬子混一色に限定。暗槓ロンは国士のみ。
- 海底直前の槓は嶺上なし流局。残2枚の場合の表示牌を確保するため、無制限槓モードでは最初に表示牌予備2枚を別に確保します。牌総数は不変で、手牌・河・副露・抜き牌・山・予備牌を合計するテストを実行します。
- 南入時は東3局終了時のトップ4万点未満を条件とし、南場では和了で誰かが4万点に達すると終了。流局は続行。トップ親の和了止めも、南入を有効にした場合は4万点到達を必要とします。
- 手動チョンボ10枚オールや打牌差し戻しはありません。違法な打牌を選択できないためです。
