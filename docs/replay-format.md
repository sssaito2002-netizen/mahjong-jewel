# LLM解析向け牌譜 v1

終了した対局の結果画面で「牌譜JSONを保存」「LLM解析用テキストを保存／コピー」を使用します。四麻・五等サンマ・近くの人とのルーム対戦に対応。対戦成績の各対局からも再出力できます。機能追加前の牌譜は復元できません。

端末保存は最大10対局、JSON文字数目安180万字の範囲で古い牌譜から削除します。通常の成績・累積は削除しません。容量不足時は画面上のデータを直接出力できます。新しい対局へ進む前に出力してください。対局中の牌譜出力はありません。ルーム対戦では終了後にのみ参加者へ全情報を配信し、対局中は送信しません。

独自JSON形式 `schema=houseki-mahjong-replay`, `schemaVersion=1`。天鳳等の既存ビューアーの取込形式ではありません。JSONはUTF-8、テキストは解析指示と同じJSONを含みます。

| フィールド | 意味 |
| --- | --- |
| matchId/mode/startedAt/finishedAt/build | 対局識別、four/sanma、日時、Web資産ビルド識別 |
| players | 固定ID、名前、controller（human/cpu/unknown） |
| rules | 採用した全設定、宝石の効果・物理トークン、華・ポッチ、サンマの全オプションと説明 |
| notation | 牌コード・特殊牌・手牌文字列・副露・方向記号の説明 |
| events | seq順の配牌・ツモ・打牌/行動・鳴き・槓・華・和了/流局結果。四麻はエンジン生イベントを格納 |
| decisions | seq、playerId、controller、chosen、legalActions、view。CPUも全員記録 |
| results | 順位・最終点・順位チップ・祝儀 |
| rawPaipu | 四麻のエンジン元牌譜。サンマはnull（eventsを使用） |

各decision.viewは判断時点の本人の手牌・ツモ牌・河・副露・公開済みのオープン手牌・点数・供託・本場・表ドラ等です。サンマは北・華・シュバ使用状況も含みます。四麻のplayerIdsBySeatは各局の風席を固定IDへ変換します。CPUの打牌評価はcontroller=cpuかつchosen.dapai（四麻）/chosen.discard（サンマ）を抽出してください。人間の同様の行も同じ条件で比較できます。

**評価は対象decisionのview・legalActions・rulesだけを使ってください。** events/rawPaipuには終局後の検証のため全員の配牌・ツモ・和了結果がありますが、相手の伏せ手牌・未公開裏ドラ・次のツモはその時点の判断材料に含めません。山の事前配列は出力しません。自動ツモ切り・一択の選択も行動記録として残します。牌譜は再開用セーブや乱数シードの再実行形式ではありません。

この機能はデータの出力であり、自動でLLMへ送信・課金したり、打牌の良否を計算したりはしません。解析用テキストを利用者が任意のLLMへ渡します。名前も含まれるため、共有先は利用者が選んでください。
